# Aventura de Monstruos — Exploración

Juego de exploración de mazmorras con monstruos, gemas y niveles progresivos. HTML5 Canvas.

## 🎮 Controles
- WASD / Flechas: mover
- Espacio: atacar (en la dirección del movimiento)
- P: pausa

## ✨ Características
- Mazmorras generadas aleatoriamente con salida.
- Recolecta gemas para sumar puntos.
- Combate cuerpo a cuerpo contra slimes y demonios.
- Vida, puntuación, niveles y aumento de dificultad.
- Efectos de partículas y mensajes en pantalla.

## ▶️ Cómo jugar
Abre `index.html` en un navegador moderno, pulsa "Entrar".
